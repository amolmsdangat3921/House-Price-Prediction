# House-Price-Prediction
One small regression project end-to-end and understand what each metric is actually measuring.

1. Project objective

Goal: Predict house prices using features such as:

* Area

* Number of bedrooms

* Number of bathrooms

* Age of property

* Distance from city center

We'll build a Linear Regression model and evaluate it using:

MAE → RMSE → R² → Adjusted R²


A small Machine Learning regression project built to understand the fundamentals of Linear Regression using Python and Scikit-learn.
